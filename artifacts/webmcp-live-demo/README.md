# OrgMemory live WebMCP demo

This artifact is assembled from screenshots captured against `https://orgmemory.vercel.app` during real browser interactions. The browser queries were typed and submitted against the signed-in production workspace; only idle waiting is compressed in the edit.

Routes shown: `/`, `/workspace`, `/webmcp`, `/approvals`, and `/loop`.

The Remotion source lives in `../webmcp-demo/remotion/src/live` and is registered as the `OrgMemoryLiveWebMCP` composition. Render output is written to `orgmemory-live-webmcp-demo.mp4` in this directory.
